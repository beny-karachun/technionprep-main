# algoprep.com

Landing page for AlgoPrep, linking to the subdomain study sites
(sivug, python, physics2, bfe) and the Python homework tester. Plain static
HTML/CSS with a tiny JS language toggle; no build step. Hosted on GitHub Pages
(`CNAME` = algoprep.com).

AlgoPrep is an independent website and is not affiliated with or endorsed by
the Technion – Israel Institute of Technology.

Card thumbnails in `assets/shots/` are screenshots of the live subsites (Oct 2026).
