(sivug, python, physics2, bfe) and the Python homework tester. Plain static HTML/CSS with a tiny JS
language toggle; no build step. Hosted on GitHub Pages (`CNAME` = technionprep.com).

Card thumbnails in `assets/shots/` are screenshots of the live subsites (Oct 2026).
